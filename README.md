# StudyScroll

A single-page, TikTok-inspired study feed that replaces doomscrolling with rapid-fire multiple-choice practice. Create subjects, attach your lecture notes, and publish questions into an endless stream your peers can save for later review.

## Getting started
1. Open `index.html` in your browser (no build or install steps required).
2. Scroll the feed, answer questions, and tap **Save** to bookmark items for review.
3. Create subjects, upload notes (paste text or drop a `.txt` file), and publish your own multiple-choice questions.

State is persisted locally in `localStorage`, so you can refresh without losing your sessions.
